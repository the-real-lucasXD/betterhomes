# Betterhomes

A Minecraft Fabric mod that enhances the vanilla teleporting systems,  by adding features like private/public home waypoints, as well as teleport systems.

## Disclaimer

This mod is still in its Beta stage, meaning not all planned features have been implemented. Please expect bugs or logic gaps.

## Current Features
- Config system with various config options that will be used in upcoming features, allowing for more customization
